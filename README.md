Название проекта: SkyproWallet

Учебный проект по управлению личными финансами.
Реализован на React.

Функционал

- Авторизация: Защищённый вход и регистрация пользователей.
- Управление расходами: Добавление, просмотр и удаление транзакций в реальном времени.
- Интерактивный анализ: Визуализация расходов в виде столбчатых диаграмм по категориям.
- Умный календарь.
- Фильтрация таблицы расходов по описанию.
- Адаптивность: Соответствие макетам Figma для десктопных и мобильных устройств.

Принципы разработки (Clean Code)
Проект реализован с соблюдением принципов:

- KISS: Код написан максимально просто и понятно.
- DRY: Избегание дублирования логики.
- YAGNI: Реализован только необходимый функционал без избыточности.

Инструкция по запуску

1. Клонируйте репозиторий:
2. Установите зависимости: `npm install`
3. Запустите проект в режиме разработки: `npm run dev`
